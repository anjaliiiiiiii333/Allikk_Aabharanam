### Project Description
"Digital Accessories" is a Windows desktop application that visually attaches decorative keychains and accessories to real files, folders, and shortcuts on your Windows desktop. As you drag your icons across the desktop, the accessories smoothly follow them in real time without modifying the files in any way.

### The Problem (that doesn't exist)
Real physical folders, notebooks, and binders can have cute keychains, charms, and stickers attached to them. But digital Windows desktop icons are boring, flat, and cannot hold decorative accessories.

### The Solution (that nobody asked for)
Give every desktop file, folder, and application shortcut its own physical-style digital accessory! A transparent, click-through overlay hooks a pastel fish keychain with beads to your icons and follows them around the screen as you work.

### Technologies/Components Used
For Software:
- Languages: Python 3.10+ (compatible with Python 3.12, 3.13, 3.14)

- Tools: Windows Shell `IFolderView`, `IShellBrowser`, Win32 `WS_EX_TRANSPARENT` & `WS_EX_LAYERED`
