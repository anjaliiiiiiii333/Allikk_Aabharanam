## 🏗️ Architecture Overview

```
User Interface (WPF)
    ↓
    ├─→ Detect Desktop Items
    │    └─→ DesktopIconDetector
    │         └─→ UIAutomation (FindWindow + TreeWalker)
    │              └─→ Reads: Name, BoundingRectangle (position/size)
    │
    ├─→ Create Overlay
    │    └─→ KeychainOverlay
    │         └─→ CreateWindowEx (WS_EX_LAYERED | WS_EX_TRANSPARENT)
    │         └─→ UpdateLayeredWindow (32-bit RGBA PNG + alpha blending)
    │
    └─→ Track Position (Background Thread)
         └─→ KeychainTracker
              ├─→ Loop every 100ms
              ├─→ Get current position (UIAutomation)
              └─→ Update overlay position (SetWindowPos)
```

## 🔧 Technical Highlights

### Desktop Detection
- **Method**: Windows UIAutomation
- **Entry Point**: FindWindow("Progman") → Program Manager window
- **Enumeration**: TreeWalker.ControlViewWalker
- **Data**: element.Current.BoundingRectangle (screen coordinates)
- **Why**: Universal, DPI-aware, works for all item types, non-invasive

### Overlay Rendering
- **Window Styles**:
  - `WS_EX_LAYERED`: Alpha blending support
  - `WS_EX_TRANSPARENT`: Click-through (mouse passes through)
  - `WS_EX_TOPMOST`: Always visible
  - `WS_EX_NOACTIVATE`: Doesn't steal focus
- **Update Method**: `UpdateLayeredWindow()` (efficient, no redraw overhead)
- **Format**: 32-bit RGBA PNG (full alpha transparency)

### Position Tracking
- **Interval**: 100ms (10 updates/second, imperceptible to user)
- **Thread**: Background Task (UI never blocked)
- **Cancellation**: CancellationToken (clean shutdown)
- **Retry Logic**: 3 retries on temporary failure
- **Failure Detection**: ItemLost event propagated to UI

```bash

dotnet build --configuration Release
```

### Run
```bash
dotnet run
# or
bin\Release\net8.0-windows\DesktopKeychainApp.exe
```

### Usage
1. Click "Refresh Desktop Items"
2. Select a desktop item
3. Click "Attach Keychain"
4. Drag item around desktop
5. Watch keychain follow!
6. Click "Detach Keychain" when done
